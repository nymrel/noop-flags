2026-08-11, this project has **zero independently verified external runs** and
**zero externally authored fixtures** recorded here.

must include:

- repository or sanitized fixture;
- Python and `noop-flags` version or commit;
- exact invocation;
- expected and actual result;
- classification: true finding, false positive, false negative, or correct
  refusal/skip;

- confirmation that no secrets, customer code, or private paths were shared.

Stars, page views, and self-authored test runs do not count as independent
reproduction. They may be tracked separately without being described as
adoption.
