# Code of conduct

We want this project to be a useful, low-drama place to improve developer
tooling. Be respectful, discuss the work rather than the person, accept
evidence-based correction, and avoid harassment, discrimination, threats,
doxxing, or disclosure of private information.

Maintainers may edit or remove contributions that violate these expectations
and may temporarily or permanently restrict participation when needed to keep
the project safe.

For public project-space concerns, use GitHub's moderation and report-abuse
tools. Do not publish sensitive personal information in an issue. Security
reports belong in the private route documented in [SECURITY.md](SECURITY.md).
