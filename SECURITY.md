# Security policy

## Supported versions

`noop-flags` has not published its first release. The `main` branch receives
security fixes, but it does not carry a support-time guarantee or security
certification.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting form:

https://github.com/nymrel/noop-flags/security/advisories/new

Please include the affected commit or version, impact, a minimal reproduction,
and whether public disclosure is already planned. Do not place secrets,
customer code, or vulnerability details in a public issue.

Ordinary false positives and false negatives are product-quality reports, not
security reports; use the corresponding public issue template with a sanitized
fixture.
